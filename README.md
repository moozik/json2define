# json2define

Turn arbitrary JSON into compilable Go initialization code.

You already know the Go struct that a JSON document maps to. `json2define`
walks that struct type with reflection and emits a complete, gofmt-ed Go
source file whose variable literal is initialized from the JSON and
guaranteed to match the struct's field names and field types.

## Usage

```go
package main

import (
	"fmt"
	"reflect"

	"github.com/moozik/json2define"
	"github.com/your/app/config"
)

func main() {
	data := []byte(`{"name":"svc","replicas":3,"tags":["a","b"]}`)

	src, err := json2define.Generate(
		reflect.TypeOf(config.Config{}),
		data,
		json2define.WithPackageName("config"),
		json2define.WithVarName("Default"),
	)
	if err != nil {
		panic(err)
	}
	fmt.Println(src)
}
```

Output (gofmt-formatted, no imports needed here):

```go
// Code generated by json2define; DO NOT EDIT.

package config

var Default Config = Config{
	Name:     "svc",
	Replicas: 3,
	Tags: []string{
		"a",
		"b",
	},
}
```

If the generated file lives in the same package as the struct, pass
`json2define.WithSamePackagePath("github.com/your/app/config")` so the type
is emitted without a qualifier.

There is also a generic entry point:

```go
src, err := json2define.GenerateFor[config.Config](data)
```

## What is supported

- Structs (json tags, `omitempty`, `,string`, `-`, case-insensitive matching,
  embedded structs), pointers, slices, arrays, maps and scalar kinds.
- Empty interfaces (`any` / `interface{}`) by inferring a literal from the
  JSON; numbers become `float64` to match `encoding/json`.
- `[]byte` values from base64 JSON strings and `json.RawMessage`.
- `time.Time` values parsed from RFC 3339 and a few common layouts.
- Automatic import management and a small `json2definePtr` helper for
  pointer-to-primitive values.
- Unknown JSON keys are ignored; missing fields are left at their zero value.

## Development

```sh
go test ./...
```

The test suite includes an integration test that writes the generated code
into a throwaway module, compiles it, and checks the initialized value is
`reflect.DeepEqual` to what `encoding/json` would have produced.
