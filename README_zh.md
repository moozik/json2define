# json2define

将任意 JSON 转换为可直接编译的 Go 初始化代码。

当你已经知道某段 JSON 对应的 Go struct 时，`json2define` 会通过反射遍历该
struct 类型，生成一个完整的、经过 gofmt 格式化的 Go 源文件。文件中的变量字面量
由 JSON 初始化，并保证与 struct 的字段名和字段类型一致。

## 用法

```go
package main

import (
	"fmt"
	"reflect"

	"github.com/moozik/json2define"
	"github.com/your/app/config"
)

func main() {
	data := []byte(`{"name":"svc","replicas":3,"tags":["a","b"]}`)

	src, err := json2define.Generate(
		reflect.TypeOf(config.Config{}),
		data,
		json2define.WithPackageName("config"),
		json2define.WithVarName("Default"),
	)
	if err != nil {
		panic(err)
	}
	fmt.Println(src)
}
```

输出（已由 gofmt 格式化，此处无需任何 import）：

```go
// Code generated by json2define; DO NOT EDIT.

package config

var Default Config = Config{
	Name:     "svc",
	Replicas: 3,
	Tags: []string{
		"a",
		"b",
	},
}
```

如果生成的文件与 struct 位于同一个包内，请传入
`json2define.WithSamePackagePath("github.com/your/app/config")`，这样类型会
以不带包限定符的形式输出。

另外还提供了泛型入口：

```go
src, err := json2define.GenerateFor[config.Config](data)
```

## 支持的特性

- Struct（json tag、`omitempty`、`,string`、`-`、大小写不敏感匹配、嵌入
  struct），以及指针、切片、数组、map 和各种标量类型。
- 空接口（`any` / `interface{}`）：根据 JSON 推断字面量；数字会转为
  `float64`，与 `encoding/json` 的行为保持一致。
- 由 base64 JSON 字符串生成 `[]byte`，以及 `json.RawMessage`。
- 从 RFC 3339 及若干常见布局解析出的 `time.Time`。
- 自动管理 import。指针使用 Go 1.26 的 `new(expr)` 内建语法生成，无需任何辅助
  函数。
- 忽略 JSON 中未知的键；缺失的字段保持零值。

## 开发

需要 Go 1.26 或更高版本：生成的代码使用了 `new(expr)` 内建语法。

```sh
go test ./...
```

测试套件包含一个集成测试：它把生成的代码写入一个临时模块、编译并运行，
然后检查初始化后的值与 `encoding/json` 解析结果是否 `reflect.DeepEqual`。
